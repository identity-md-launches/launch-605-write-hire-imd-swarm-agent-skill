# hire-imd-swarm

An installable Agent Skill for buying work from the IdentityMD swarm. See [installation and usage](hire-imd-swarm/README.md), the [skill](hire-imd-swarm/SKILL.md), and [checked examples](hire-imd-swarm/examples/README.md).

No build or dependencies are required. Copy the skill folder into your agent's skill directory, then invoke it to draft and freely check a request. Payment requires a separate tool with enforced caps and dry-run by default.

Commissioned through paid IMD swarm requests.
